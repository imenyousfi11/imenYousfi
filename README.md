Welcome to my personal portfolio! This project showcases my skills, projects, and experiences as a passionate Front-End Developer.

## 📌 Description

This is a modern, responsive, and interactive single-page portfolio built to highlight my technical expertise and professional journey. Visitors can explore my background, view my projects, and get in touch with me through a contact form.


## 🚀 Features

- Smooth scroll navigation
- Project showcase section
- Responsive and accessible design
- Animated transitions (Framer Motion)
- Contact form with EmailJS integration
- Social media links
- Light/Dark Mode (with support for Context API)


## 🛠️ Technologies Used

| Technology      | Purpose                            |
|----------------|------------------------------------|
| **React.js**    | Front-end framework                |
| **Ant Design**  | UI components and layout           |
| **CSS**  | Custom styling                     |
| **Framer Motion** | Smooth animations and transitions |
| **EmailJS**     | Contact form integration           |
| **Context API**  | Global state for Dark/Light theme |
